# HTTPSと証明書の設定

`--tls-cert` と `--tls-key` の両方を設定するとTLSを有効にします。既定では同じTCPポートでHTTPとHTTPSを受け付けます。平文HTTPを拒否する場合は `--https-only` を指定してください。

```powershell
./TranscriptionServer.exe --local --host 127.0.0.1 --port 8769 --tls-cert C:\certificates\server-chain.pem --tls-key C:\certificates\server.key --https-only
```

証明書はサーバーへ接続するIPアドレスまたはDNS名をSANに含め、信頼できる認証局から取得します。上記のファイル名は利用環境に合わせて変更してください。秘密鍵はサーバーの実行ユーザーだけが読める場所に保存してください。

LANの利用PCでは、組織や利用者が管理する認証局の公開CA証明書を、管理者から信頼できる経路で受け取ります。別経路で示された拇印とSHA256を照合し、秘密鍵を含まないことを確認してから、端末の管理方針に従って信頼登録してください。

サーバー秘密鍵、CA秘密鍵、秘密鍵付きPFXをクライアントPCへ配布しないでください。警告を無視した接続やTLS検証の無効化を前提にしません。

登録後、ブラウザーで接続先を開き、証明書の期限・対象ホスト名・信頼が有効であることを確認します。CORSのallow-origin設定や接続キー、ブラウザーのローカルネットワーク許可はTLSとは別に確認してください。
