# v0.1.17 Windows x64 展開型配布

公開ソースの初回配布として、`v0.1.17` に展開型ZIPとSHA-256一覧を用意した。プログラムの採用コミットは `e6e054c61a9f4d351ae199a96c5d8c01d3e4b902`。署名付きInno Setupは配布対象外。展開型ZIPのビルドは `scripts/build-release.py --portable-release` を使う。

| 確認項目 | 結果 |
| --- | --- |
| バイナリとアーカイブ | Windows x64向けのReleaseビルドに成功。5,769,894 bytes。SHA-256は `7e0240c3b3f16c386ed42420e3703df5bfa0ec022ce5d33b8657e1e298a80b17`。採用コミットと展開後のBUILD.jsonを照合した。 |
| 配布条件の試験 | Pythonの27件中25件が成功、2件は条件付きスキップ。ZIP専用経路の出力と既存インストーラーの署名ゲートを確認した。Webの18件も成功した。 |
| 公開前の秘密検査 | 追加コミット2件と配布ZIPの展開内容を個別に検査し、検出0件。モデル、実行時データ、試験用音声は配布物の対象外。 |
| 隔離起動と文字起こし | ZIPから展開したEXEをWindows 11 x64上で起動。認証なしではHTTP 403、認証済みのローカルAPIでは200。合成日本語音声の本文と時刻付き2区間を取得した。Whisper Baseと媒体処理は検証環境に用意した。 |
| 管理画面 | 内蔵ブラウザーでバージョン、同じPCからの接続案内、キーボードでの閉じる操作、Whisper Baseのロードと解放を確認した。GPU候補がない環境ではGPU操作は無効だった。 |

認識ランタイムを未配置の別PCでの自動導入、GPUでの認識、LANからの利用は今回の配布候補では未検証。配布版の操作確認には隔離した専用データとポートを使用した。

公開後、[GitHub Releases v0.1.17](https://github.com/KotorinChunChun/TranscriptionServer/releases/tag/v0.1.17)からZIPとSHA-256一覧を匿名で取り直し、公開前の容量・SHA-256との一致を確認した。モデル解放のブラウザー記録はデコードと開始・途中・終了の画面を確認した。記録は時刻付き静止画によるもので、フレーム間隔は最大0.877秒。
